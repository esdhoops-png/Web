Fuente de datos

Descarga de una vez todos los negocios de la isla que tienen teléfono y no tienen web registrada en OpenStreetMap. Es gratis, pero OSM no tiene todos los negocios y a veces le falta la web aunque exista: usa el botón «Comprobar en Google» antes de llamar.

Usa la API de Google Places (New). Google indica si el negocio tiene web, así que el resultado es mucho más fiable. Cada búsqueda cuesta dinero (hay un cupo gratis al mes): revisa la estimación antes de lanzar. La clave se guarda solo en este navegador.
